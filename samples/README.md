# Benchmark samples

The three PDF files in this directory are synthetic scans generated by
`SampleDocumentGenerator`. They contain only project-authored text rendered into raster images;
there is no external dataset or third-party document content. The rendered content and noise are
deterministic; PDF container identifiers may differ when the files are regenerated.

| File | Pages | Scan profile |
| --- | ---: | --- |
| `scanned-small.pdf` | 1 | clean, high contrast |
| `scanned-medium.pdf` | 2 | mildly reduced contrast and deterministic speckle noise |
| `scanned-long.pdf` | 4 | lower contrast and more deterministic speckle noise |

The files are covered by the repository's license and may be redistributed with the project.
Regenerate them from the repository root after packaging:

```bash
java -jar target/ocr-laundry.jar generate-samples samples
```
